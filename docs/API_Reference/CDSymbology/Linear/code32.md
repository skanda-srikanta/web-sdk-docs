## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable Code11 symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable Code32.
const CdSymbology = new CDSymbology()
set CdSymbology.Code32.enable(value: boolean);
get CdSymbology.Code32.enable(): boolean;
```
</CodeBlock>
