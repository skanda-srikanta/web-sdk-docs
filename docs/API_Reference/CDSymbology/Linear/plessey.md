## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable Plessey symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable Plessey.
const CdSymbology = new CDSymbology()
set CdSymbology.Plessey.enable(value: boolean);
get CdSymbology.Plessey.enable(): boolean;
```
</CodeBlock>
