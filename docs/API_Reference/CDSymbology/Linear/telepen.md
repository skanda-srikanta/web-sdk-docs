## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable Telepen symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable Telepen.
const CdSymbology = new CDSymbology()
set CdSymbology.Telepen.enable(value: boolean);
get CdSymbology.Telepen.enable(): boolean;
```
</CodeBlock>
