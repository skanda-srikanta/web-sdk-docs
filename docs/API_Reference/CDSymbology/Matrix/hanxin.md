## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable HanXinCode symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable HanXinCode.
const CdSymbology = new CDSymbology()
set CdSymbology.HanXinCode.enable(value: boolean);
get CdSymbology.HanXinCode.enable(): boolean;
```
</CodeBlock>
