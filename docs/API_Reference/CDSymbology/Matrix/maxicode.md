## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable MaxiCode symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable MaxiCode.
const CdSymbology = new CDSymbology()
set CdSymbology.MaxiCode.enable(value: boolean);
get CdSymbology.MaxiCode.enable(): boolean;
```
</CodeBlock>
