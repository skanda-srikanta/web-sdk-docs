## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable AustraliaPost symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable AustraliaPost.
const CdSymbology = new CDSymbology()
set CdSymbology.AustraliaPost.enable(value: boolean);
get CdSymbology.AustraliaPost.enable(): boolean;
```
</CodeBlock>
