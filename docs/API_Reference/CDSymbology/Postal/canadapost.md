## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable CanadaPost symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable CanadaPost.
const CdSymbology = new CDSymbology()
set CdSymbology.CanadaPost.enable(value: boolean);
get CdSymbology.CanadaPost.enable(): boolean;
```
</CodeBlock>
