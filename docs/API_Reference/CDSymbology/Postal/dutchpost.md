## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable DutchPost symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable DutchPost.
const CdSymbology = new CDSymbology()
set CdSymbology.DutchPost.enable(value: boolean);
get CdSymbology.DutchPost.enable(): boolean;
```
</CodeBlock>
