## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable JapanPost symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable JapanPost.
const CdSymbology = new CDSymbology()
set CdSymbology.JapanPost.enable(value: boolean);
get CdSymbology.JapanPost.enable(): boolean;
```
</CodeBlock>
