## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable KoreaPost symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable KoreaPost.
const CdSymbology = new CDSymbology()
set CdSymbology.KoreaPost.enable(value: boolean);
get CdSymbology.KoreaPost.enable(): boolean;
```
</CodeBlock>
