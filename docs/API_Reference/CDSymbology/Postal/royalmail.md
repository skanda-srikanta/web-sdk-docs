## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable RoyalMail symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable RoyalMail.
const CdSymbology = new CDSymbology()
set CdSymbology.RoyalMail.enable(value: boolean);
get CdSymbology.RoyalMail.enable(): boolean;
```
</CodeBlock>
