## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable UPU symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable UPU.
const CdSymbology = new CDSymbology()
set CdSymbology.UPU.enable(value: boolean);
get CdSymbology.UPU.enable(): boolean;
```
</CodeBlock>
