## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable USPSIntelligent symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable USPSIntelligent.
const CdSymbology = new CDSymbology()
set CdSymbology.USPSIntelligent.enable(value: boolean);
get CdSymbology.USPSIntelligent.enable(): boolean;
```
</CodeBlock>
