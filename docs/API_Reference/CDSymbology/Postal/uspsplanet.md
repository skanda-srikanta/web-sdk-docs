## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable USPSPlanet symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable USPSPlanet.
const CdSymbology = new CDSymbology()
set CdSymbology.USPSPlanet.enable(value: boolean);
get CdSymbology.USPSPlanet.enable(): boolean;
```
</CodeBlock>
