## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable USPSPostnet symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable USPSPostnet.
const CdSymbology = new CDSymbology()
set CdSymbology.USPSPostnet.enable(value: boolean);
get CdSymbology.USPSPostnet.enable(): boolean;
```
</CodeBlock>
