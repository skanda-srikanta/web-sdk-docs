## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable CodablockF symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable CodablockF.
const CdSymbology = new CDSymbology()
set CdSymbology.CodablockF.enable(value: boolean);
get CdSymbology.CodablockF.enable(): boolean;
```
</CodeBlock>
