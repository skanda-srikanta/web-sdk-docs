`Code49` Class supports all the public APIs for `Code49` Symbology.

import Tabs from '@theme/Tabs';

## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable Code49 symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable Code49.
const CdSymbology = new CDSymbology()
set CdSymbology.Code49.enable(value: boolean);
get CdSymbology.Code49.enable(): boolean;
```
</CodeBlock>
