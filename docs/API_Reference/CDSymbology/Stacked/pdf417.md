`PDF417` Class supports all the public APIs for `PDF417` Symbology.

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

## Setters and Getters:

### <u>enable</u>

`enable` is used to enable or disable PDF417 symbology.

<CodeBlock language="js">

```js
//Use Boolean value to enable or disable PDF417.
const CdSymbology = new CDSymbology()
set CdSymbology.PDF417.enable(value: boolean);
get CdSymbology.PDF417.enable(): boolean;
```
</CodeBlock>

---

### <u>microPDF417</u>

`microPDF417` is used to enable or disable  MicroPDF417 symbology.  Defaults to false for iOS and Xamarin.

<CodeBlock language="js">

```js
const CdSymbology = new CDSymbology()
set CdSymbology.PDF417.microPDF417(value: boolean);
get CdSymbology.PDF417.microPDF417(): boolean;
```
</CodeBlock>
